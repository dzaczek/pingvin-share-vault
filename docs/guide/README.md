# Pingvin Share X guides

Documentation for [dzaczek/pingvin-share-x](https://github.com/dzaczek/pingvin-share-x). Start with the [README](../../README.md) for an overview and a quick start.

| Guide | Read it when you want to |
|---|---|
| [Installation](installation.md) | run a release image or build from source, set up volumes, a reverse proxy or ClamAV |
| [Upgrading](upgrading.md) | back up, move to a newer release, or come over from smp46/pingvin-share-x |
| [Configuration](configuration.md) | use `config.yaml`, find the settings this fork adds, and know which upstream pages still apply |
| [Administration](administration.md) | work with the share list, blocking, the access log, VirusTotal lookups, antivirus scanning and anonymous shares |
| [Releases](releases.md) | understand the version numbers and how a release and its images are made |
| [Troubleshooting](troubleshooting.md) | fix a common problem |
| [Development](development.md) | run the code locally, test it and open a pull request |

The other content of the `docs` folder is a copy of the [upstream documentation site](https://smp46.github.io/pingvin-share-x/) and is not published from this repository. [Configuration](configuration.md#upstream-documentation-that-still-applies) lists which of its pages apply here.
